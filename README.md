## 📖 Proje Hakkında / About
**TR:** Tattoo Studio, dövme sanatçılarının çalışmalarını sergileyebileceği, müşterilerin stüdyo hakkında bilgi alabileceği ve randevu / iletişim süreçlerini yönetebileceği şık, karanlık temalı (dark mode) ve estetik bir frontend arayüzüdür.

**EN:** Tattoo Studio is a sleek, dark-themed, and aesthetic frontend interface where tattoo artists can showcase their work, customers can learn about the studio, and manage appointment/contact processes.

---

## ✨ Özellikler / Key Features
- 🎨 **Sanatçı Galerisi / Artist Gallery:** Stüdyonun ve sanatçıların çalışmalarını gözler önüne seren estetik portfolyo alanı. / Aesthetic portfolio section showcasing studio and artist works.
- 🖤 **Karanlık Tema Tasarımı / Dark Mode Concept:** Dövme sektörüne uygun, göz yormayan ve karizmatik renk paleti. / Charismatic and eye-friendly color palette fitting the tattoo industry.
- 📅 **Randevu & İletişim / Appointment & Contact:** Müşterilerin stüdyo ile kolayca iletişime geçmesini sağlayan form ve bilgi bölümleri. / Form and info sections allowing customers to easily connect with the studio.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil ve masaüstü cihazlarda kusursuz uyum. / Seamless compatibility on mobile and desktop devices.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik web yapılandırması / Semantic web structure
* **CSS3:** Özel stiller, esnek layoutlar (Flexbox/Grid) ve dark theme tasarımı / Custom styles, flexible layouts, and dark theme design
* **JavaScript (ES6+):** Sayfa içi dinamik etkileşimler ve animasyonlar / In-page dynamic interactions and animations
